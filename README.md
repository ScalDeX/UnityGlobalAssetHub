# UnityGlobalAssetHub
A lightweight cross-project Asset &amp; Script manager for Unity. Store and transfer reusable C# scripts, UI elements, and folders between projects in one click. Features Drag &amp; Drop, batch import, and multi-language support (EN/RU/JA).
# 📦 Global Asset Hub for Unity

**Global Asset Hub** is a lightweight, cross-project editor extension for Unity that allows game developers to instantly store, organize, and transfer reusable C# scripts, UI elements, and asset folders between different Unity projects.

## 🔥 Key Features

- **Cross-Project Storage:** Assets are stored globally in your system (`AppData`), making them available across all Unity projects on your PC.
- **Drag & Drop Workflow:** Drag scripts or folders directly from your Unity `Project` window into the Hub.
- **Batch Import:** Select multiple assets using checkboxes and import them all at once.
- **Folder Tree Hierarchy:** Full support for nested directories with expandable foldout views.
- **Multi-Language UI:** Built-in localization for **English**, **Russian (Русский)**, and **Japanese (日本語)** with persistent state.
- **Zero Dependencies:** Single C# Editor script. No external DLLs or complex setups required.

## 🚀 Quick Start

### Installation
1. Download the latest `GlobalAssetHub.unitypackage` from the [Releases](../../releases) section.
2. Drag and drop the `.unitypackage` into your Unity project.
3. Open the tool via Unity top menu: **`Tools -> Global Asset Hub`**.

## 💡 How to Use

1. **Save Assets:** Drag any `.cs` script or folder from your `Project` window into the dotted drop zone in the **Global Asset Hub** window.
2. **Import Assets:** Open **Global Asset Hub** in any other Unity project, check the items you need, and click **Import Selected**.
3. **Change Language:** Use the globe icon 🌐 in the top right corner to switch languages.

---

## 🛠 Specifications

- **Target Path:** `%AppData%/Roaming/UnityGlobalAssetHub/`
- **Import Location:** `Assets/ImportedFromHub/`
- **Compatibility:** Unity 2020.3 LTS and newer (UI Toolkit & IMGUI supported).
